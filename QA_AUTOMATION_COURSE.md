# ZAŁOŻENIA KURSU

## Cel

Zbudować od podstaw do poziomu enterprise profesjonalny framework QA
Automation, a przy okazji rozwinąć nowoczesną Javę, wzorce projektowe,
API testing i praktyczne wykorzystanie AI.

## Mój poziom

QA Automation Engineer. Znam Javę, Selenium/Selenide, Cucumber, REST
Assured, Maven, JUnit i AssertJ. Nie jestem początkujący.

## Stack

-   Java 21
-   Maven
-   Selenide
-   JUnit 5
-   AssertJ
-   REST Assured
-   Jackson
-   Git
-   IntelliJ IDEA

## Główne aplikacje treningowe

-   DemoQA --- UI, formularze i komponenty
-   DataTables --- tabele, mappery i generyki
-   OrangeHRM --- realistyczna aplikacja biznesowa
-   Practice Software Testing --- większy projekt UI/API

## Zasady każdej lekcji

1.  Zacznij od problemu zbliżonego do realnej pracy QA Automation.
2.  Wyjaśnij cel lekcji.
3.  Wyjaśnij tylko potrzebną teorię.
4.  Implementuj krok po kroku.
5.  Pokaż pełny kod.
6.  Wyjaśnij ważne fragmenty.
7.  Pokaż refaktoryzację.
8.  Daj zadanie praktyczne.
9.  Rozwiązanie zadania pokaż dopiero po mojej prośbie.
10. Po lekcji projekt ma być uruchamialny.
11. Nie przeskakuj kilku lekcji.
12. Nie stosuj wzorców i abstrakcji bez uzasadnienia.
13. Jeżeli istnieje prostsze rozwiązanie, porównaj je z rozwiązaniem
    frameworkowym.
14. Zwracaj uwagę na czytelność, testowalność, utrzymanie i SOLID.

## Git

`feature/qa-automation-framework`

Przykładowe commity:

`lesson-001: initialize project`\
`lesson-002: add project structure`\
`lesson-003: add first UI test`
